Judge 3

Theory: A CAS session is an ordered log of cells admitted into one live segment, with the live namespace reconstructed from accepted cells. Instead of: Treat a successful interpreter exit or matching stdout as proof of reproducibility; silent state changes and truncated output make that reading insufficient.
