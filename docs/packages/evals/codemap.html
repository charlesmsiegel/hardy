evals as a model of its problem

An evaluation is an identified procedure applied to an explicit selection, with rows reconstructed from recorded runs. Pooling combines compatible evidence instead of assuming all historical scores are interchangeable.

Chosen interpretation. Trusting runner totals and pooling by model name would conceal procedure drift, changed environments, and duplicate samples. src/hardy/evals/selection.py:9
