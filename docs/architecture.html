Hardy — an agentic harness for theorem proving

architecture overview · DESIGN.md · Lean 4 + LaTeX, any model

The wager: what Claude Code did for programming, a harness can do for mathematics — because here verification is free and perfect. The Lean kernel grades every attempt, and the harness's job is to keep any model in a tight loop with that signal.

IN → OUT The output contract LaTeX always · Lean where possible

“Prove that √2 is irrational.”
TeX sqrt2_irrational.tex
informal proof · citations · compile-checked · always produced
∎ Sqrt2Irrational.lean
kernel-checked formal proof · whenever formalization is in reach
the request enters the workflow loop

Critique also runs standalone on any proof you hand it — yours or the literature's. Formalization doubles as hole detection: a step that resists Lean is a suspected gap.

tectonic/latexmk compile-checks every writeup — same loop shape as the kernel, weaker guarantee.
Paper store + sandbox

Why the ledger matters: a mis-formalized axiom could make False derivable — so libraries stay minimal, a skeptic reviews every axiom, cheap refutation lints run on decidable statements, and each writeup states its assumptions in prose (“assuming Theorems 3.2 and 4.1 of [smith2023modular]”) so a human can audit the trust chain without reading Lean. This is exactly how mathematicians already treat the literature — now machine-checked.
